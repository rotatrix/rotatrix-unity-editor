# Contributing

Bug reports, compatibility fixes, and editor features are welcome. Please describe
which Unity version and operating system you use, and include a small reproduction
for bugs. Discuss substantial features in an issue before starting a large change.

See [development](DEVELOPMENT.md) for builds and tests. Keep editor-only
behavior, Undo support where applicable, and existing navigation behavior in mind.
Run automated tests and describe any device checks performed in your pull request.

By submitting a contribution, you confirm that you have the right to contribute it
and agree to license it under this repository's [Elastic License 2.0](LICENSE.md).
Connection verification stays in the OpenAxis SDK; improvements should preserve it.
